# U2-ejercicio11


### Sistema de Alarmas y Monitoreo de Seguridad

Este ejercicio consiste en desarrollar un sistema de monitoreo de seguridad en Java mediante la comunicación entre objetos.

La clase `Alerta` encapsula la información de cada incidente, incluyendo el identificador de la zona, el tipo de sensor y la marca temporal. La clase `SensorPerimetral` detecta movimientos y envía las alertas a una instancia de `CentralMonitoreo`, que registra los incidentes activos en una lista y permite generar un reporte por consola.

El objetivo es practicar la **colaboración entre objetos**, el uso de referencias, la creación de objetos, las colecciones y el registro de eventos mediante métodos.
